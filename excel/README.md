# Excel Sales Analysis

This workbook demonstrates practical Microsoft Excel skills applied to a synthetic sales dataset.

## Skills Demonstrated

- Excel Tables
- Data cleaning
- SUM, AVERAGE, MAX and MIN
- SUMIFS
- XLOOKUP
- IF statements
- Conditional formatting
- KPI calculations
- Sales and attendance analysis
- Business reporting

## Key Analysis

The workbook calculates sales and employee-performance metrics and includes a KPI for total Sales Department sales from employees with attendance of at least 90%.

## AI-Assisted Analysis

AI was used to assist with formula development. The generated formulas were independently tested and verified in Excel before being included in the workbook.

## Note

The dataset is for practice and portfolio demonstration purposes.
